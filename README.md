# Attendance Tracker App

## Overview
Attendance Tracker is a mobile application designed to help teachers, students, and administrators manage attendance records efficiently. It provides a clean interface, easy navigation, and modular structure for different user roles.

## Features
👩‍🏫 Teacher Module: Mark daily attendance, view student records, and generate reports.
🎓 Student Module: Check personal attendance history and receive notifications.
🛠️ Admin Module: Manage users, classes, and overall attendance data.

## Tech Stack
Frontend: Flutter (Dart)
Backend: Firebase / REST API (configurable)
Database: Firestore / SQLite (for offline support)
